# JUKEBOX 94.3 visual demo

Open dist/index.html in a browser. All assets are local; no install or build is required.

Optional local server: python -m http.server 8430 --directory dist

One page, smooth section navigation, continuous CSS album carousel with pause control, responsive mobile menu, and a demo proposal form. No backend, analytics, API integration or data persistence. Form data never leaves the page.

Brand: the original DASTA 943 mark and graphic patterns were extracted from the supplied JUKEBOX brandbook. The dominant cream canvas follows the brief; accent colours follow the brandbook. Anton substitutes for Blare because the original font files were not supplied. DM Sans is used for body copy. Fonts are included locally.

Photography: three generated concept photographs, not documentary photographs of the station or its events.
Albums: the artwork is displayed from the supplied mockup as a labelled demo selection, not a live playlist. Replace with original high-resolution sleeves when available.
Metrics and case studies are explicitly illustrative. Social/contact destinations are labelled placeholders. Audience percentages are not verified research.

Edit dist/index.html, dist/style.css and dist/app.js. Assets are in dist/assets.

Checked in Edge at 1440, 768, 390 and 320 px widths: no page overflow, no broken images or JavaScript errors, carousel movement/pause, section navigation, mobile menu, form success and reset.
